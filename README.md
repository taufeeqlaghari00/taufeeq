# Taufeeq Laghari Portfolio — Multi-page version

Responsive static website built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `portfolio.html` — Portfolio references
- `contact.html` — Contact

## Run locally
Extract the ZIP and open the folder in VS Code. Use the Live Server extension and open `index.html` for local navigation across all pages.

## Features
- Separate pages with working navigation and shared footer
- Afacad headings and Teachers body font
- Dark/light theme toggle with saved preference
- Responsive mobile navigation
- Custom cursor for mouse/trackpad devices only
- Scroll reveal animations, respecting reduced-motion settings
- Email and WhatsApp links
- Contact form prepares an email in the visitor's default email app; it does not send form data to a server

## Before publishing
- Project cards intentionally use public reference sites and illustrative images, not invented client case studies.
- Replace reference cards with your own verified projects, screenshots and URLs as they become available.
- Fonts and project thumbnails load from external services and need an internet connection.
- Test on your hosting environment and confirm all external URLs before launch.
